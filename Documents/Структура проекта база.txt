Ты работаешь над статическим SEO-сайтом туристического сервиса EdemGo.

Домен проекта:
https://edemgo.ru

Главная задача:
полностью наполнить существующую структуру сайта контентом и сделать современный, аккуратный, дорогой на вид дизайн в стиле современных travel-tech сервисов.

ВАЖНО:
- Не использовать React/Vue/Angular.
- Не подключать тяжелые UI-фреймворки.
- Оставить проект обычным HTML + CSS + JS.
- Не менять URL-структуру без необходимости.
- Не удалять существующие страницы.
- Не придумывать backend/API.
- Пока это SEO/frontend MVP.
- В дальнейшем сайт будет интегрирован с партнерской системой продажи ЖД-билетов через SmartTravel.
- Поэтому интерфейс должен быть подготовлен под будущий билетный виджет/поиск билетов.
- Все страницы должны быть полноценными, а не пустыми шаблонами.
- Все тексты на русском языке.
- Код должен быть чистым и понятным.
- Не использовать lorem ipsum.
- Не оставлять TODO вместо реализованного интерфейса.

EdemGo — современный туристический сервис.

Тональность:
- современно;
- легко;

- уверенно;
- без канцелярита;
- без ощущения дешевого агрегатора;
- без перегруженности.

====================================
4. ДИЗАЙН
====================================

Сделать современный travel-tech дизайн.

Визуальная идея:

EdemGo должен выглядеть как настоящий коммерческий продукт, который потенциально может конкурировать визуально с крупными сервисами путешествий.

Стиль:
- clean;
- premium;
- modern;
- много воздуха;
- крупная типографика;
- аккуратные карточки;
- мягкие тени;
- большие скругления;
- качественные hover-анимации;
- хорошая мобильная версия.

Не использовать:
- кислотные цвета;
- дешевые градиенты;
- чрезмерные тени;
- визуальный шум;
- десятки разных цветов;
- огромные emoji;
- стандартный bootstrap-look;
- визуально устаревшие кнопки.

Цветовая система должна быть единой.

Предпочтение:
- глубокий темный navy/blue для основного бренда;
- белый и светло-серый фон;
- один яркий accent;
- хороший контраст текста.

Использовать CSS variables:

:root {
    --color-primary: ...;
    --color-primary-dark: ...;
    --color-accent: ...;
    --color-bg: ...;
    --color-surface: ...;
    --color-text: ...;
    --color-muted: ...;
    --color-border: ...;
    --shadow-sm: ...;
    --shadow-md: ...;
    --radius-sm: ...;
    --radius-md: ...;
    --radius-lg: ...;
}

- description;

- hover;

Особенно внимательно проверить пути из вложенных директорий.

Например:

из /routes/moscow-sochi.html

CSS должен подключаться корректно:

../css/style.css

а logo:

../images/logo.svg

а не:

/images/logo.svg

если текущая структура предполагает относительную файловую работу.

Однако если сайт предполагает размещение от корня домена, можно использовать root-relative пути:

/css/style.css
/images/logo.svg

Выбери ОДИН подход и используй его последовательно.
